# UI/UX Inspiration — Références

Ce dossier contient les ressources d'inspiration UI/UX pour le projet NTAB Energy.

## Rôle du dossier

Centraliser les références visuelles et les bibliothèques de design utilisées comme **source d'inspiration** uniquement.

## UI/UX Pro Max Skill

**Repo** : https://github.com/nextlevelbuilder/ui-ux-pro-max-skill
**Local** : `references/ui-inspiration/ui-ux-pro-max-skill/`
**Skill Claude** : `.claude/skills/ui-ux-pro-max/`

Contient : 67 styles UI, 161 palettes de couleurs, 57 pairings typographiques, 99 guidelines UX, 25 types de charts.

### Usage avec le script de recherche

```bash
# Design system complet
python3 .claude/skills/ui-ux-pro-max/scripts/search.py "energy infrastructure africa" --design-system

# Par domaine
python3 .claude/skills/ui-ux-pro-max/scripts/search.py "dark premium" --domain style
python3 .claude/skills/ui-ux-pro-max/scripts/search.py "institutional corporate" --domain color
```

## Règles d'utilisation

- Utiliser comme **inspiration** uniquement
- **Interdiction de copier** des textes, images, branding ou composants à l'identique
- Adapter systématiquement à l'identité NTAB Energy
- Toujours citer la source dans les commentaires si une idée est directement inspirée

## Types de références à ajouter ici

- Screenshots de sites inspirants (dossier `screenshots/`)
- Moodboards de direction artistique
- Palettes couleur exportées
- Typographies testées
- Composants de référence annotés
